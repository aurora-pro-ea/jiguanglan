## 💡 新手调参三大铁律 (务必牢记)

1. **不要得“参数收集癖”**
   指标互斥会导致 EA 瘫痪死机。例如：你选了 `模式 3 (追单边爆发)`，却把 `RSI` 设为 `40` (死等回调)，这两个条件在逻辑上永远不可能同时满足！
2. **想吃大单边，放宽 CCI**
   遇到大行情时，如果左下角总提示“超买限多”，说明 CCI 把你死死按住了。想做“疯狗行情”，把 CCI 阈值拉大到 `180` 以上，甚至 `250`。
3. **ADX 是永恒的风向标**
   盯盘时请根据 ADX 指标实时切换模式：
   * **ADX < 20**：市场震荡，切 **模式 0**。
   * **ADX 稳定 20+**：趋势初显，切 **模式 1**。
   * **ADX 飙破 25 且线条陡峭**：大单边来临，立刻切 **模式 2 或 3** 顺势追杀！

## 🛠️ 核心风控与功能机制

### 1. 风控线 (全局硬止损)
* **机制说明**：当 `启用 = true` 且全局硬止损设为 `200` 时，一旦当前持仓的浮亏达到 `-200` 美元/美分，EA 将强制执行全平仓。
* **注意**：极端行情下可能会有信号滑点。

### 2. 分向移动止盈 (移动获利保护)
* **参数示例**：设 `200`，回撤 `50`。
* **运行逻辑**：当价格达到 `均价 + 2 美金` 时，系统激活移动止盈机制；随后若价格回撤 `50点`（相当于 `均价 + 1.5 美金` 处），系统将强制保底平仓，锁住利润。

### 3. AOE 解套功能 (不可用场景)
请注意，AOE 解套功能在以下 **6 种情况** 下将**无法激活**：
* ❌ 未启用该功能
* ❌ 账户本身没有被套
* ❌ 账户已处于锁仓状态
* ❌ 双向深套时
* ❌ 持仓中没有盈利单
* ❌ 当前盈利单的利润不足以覆盖亏损

# 📖 极光蓝Pro V1\.08 参数面板\(F7\) 纯中文大白话说明书

当你在 MT5 图表上加载极光蓝Pro时，按 `F7` 会弹出参数设置窗口。不要被这么多参数吓到，我们把它们分成几个“战车控制区”，用大白话一个个拆解：

### 🛑 A组：风控策略底座（战车的安全气囊）

这一组决定了你能在极端的单边行情里活多久，**保命全靠它**。

- **启用=全局硬止损 ：** 战车的保命总闸。**必须设为 true \(开启\)**，下面的硬止损才会生效。

- **触发★止损★整体浮亏金额($)达此值后全部平仓割肉：** 你的底线（硬止损）。比如填 200，意思是这组单子亏了 200 美金，EA 会瞬间全部强平（割肉保本），绝不让你爆仓。

- **止损冷却\(分钟\)：** 如果真亏了上面的200美金，EA 会强制把你关在小黑屋休息多少分钟（比如 120 分钟）。防止你上头，也避开现在的极端恶劣行情。

- **启用自动浮亏锁仓 / 锁仓触发金额\($\)：** 亏多了把多空两头锁死。**小白强烈建议设为 false \(关闭\)！** 锁仓容易解仓难，看行情再决定如何解仓。

- **启用反转断臂求生：** 极光蓝的王牌自愈功能。遇到死扛行情，允许 EA “丢车保帅”割肉。**必须 true \(开启\)**。

- **断臂冷却\(分钟\)：** EA 割了一次肉后，歇几分钟再观察盘面行情继续开机。

- **反转断臂触发层数：** 割肉条件一：单边被套到了第几层（比如第 7 单）。

- **断臂容忍金额\($\)：** 割肉条件二：并且这 7 单加起来亏了多少钱。如果满足条件，EA 会果断把本次持仓的亏损单边全部平掉，强行拉低持仓成本救命。

- **断臂阈值跟随ATR \(及下面的基准值/乘数\)：** 开启后，上面的容忍金额会变成动态的。默认乘数是2倍、比如设的30，那么到了60单边就会平掉。黄金波动大它就多扛一会儿，波动小就早点割，很聪明（小白保持默认即可）。

- **魔术码标识：** EA 的身份证号！如果在一个MT5里开了两个黄金图表，这俩图表的数字**绝对不能一样**（比如一个501，一个502），否则会互相乱平仓！

- **接管魔术码\(用,隔开0为手工单\)：** 接盘侠功能。填别人 EA 的身份证号，极光蓝就能帮被套的老单解套。填 `0,` 就是接管你的手工单。

### 🧭 B组：网格执行中枢（战车的变速箱）

- **限制周期：** 极其重要的限速器！如果你选 `PERIOD_M15`（15分钟），意思是不管行情暴跌得多猛，EA 在 15 分钟内会慢慢等K线变化再加仓，过滤杂波。

- *\(本组其他参数如：止盈模式、手数模式、间距模式等，可保持默认，是经过千锤百炼的最优解\)*

### 💰 C组：止盈与回撤追踪（怎么把钱揣进口袋）

- **整体固定止盈微点：** 赚多少微点（除以10就是标准点）准备收网。

- **分向移动止盈追踪起始\(微点\) / 追踪回撤\(微点\)：** 贪婪线与保护锁。比如利润达到 200 点开启追踪，只要行情回头跌了 50 点，立刻平仓落袋为安！绝不让到嘴的鸭子飞了。

- **单笔订单硬止损(0=关)：** 物理断网保险。万一你的 VPS 断网了，券商那边跌了多少点也会强制平仓保命。

- **防守触发层数\(0=AI\) / 强制防守亏损\($\)：** 认怂机制。如果被套了（比如到了第5层），且亏了超过这个钱（比如200刀）。EA 强行放弃赚钱，只要行情回头能保本，立刻全平跑路。

### 📐 D组：手数与间距算法（网格的骨架）

- **挂单间距\(微点\) / 逆势拉伸倍数：** 基础间距，以及越往深水区走，网格拉得越开的倍数（防守形变）。

- **起始手数 / 手数倍数：** 第一单多大，后面乘以多少倍。1\.1倍极其安全，拒绝无脑重仓。

- **最大层数：** **物理死墙！** 如果设为 11，单边最多只允许开 11 单，到了 11 单死活不再开，焊死最大风险。

- *\(本组下方的 ATR 参数是让网格像呼吸一样根据波动变宽变窄，保持默认即可\)*

### 🪚 E组：AOE解套与拔钉子（战车的医疗抢救室）

- **首单冷却\(秒\)：** 平仓后歇几秒。

- **启用=AOE解套：** 解套洗地功能！必须 `true`。

- **AOE起爆蓄能\($\)：** 凑够多少钱的利润去炸毁亏损单。小账户设小点（如3\~5刀），大账户设大点（如10\~30刀）。

- **利润留存率\(0\.9=90%\)：** 赚的钱 90% 拿去救灾解套，剩下的 10% 强行塞进你口袋，让你解套的同时还能赚钱。

- **强制唤醒金额\(0=关\) / 强制唤醒层数\(0=关\)：** 抢救室的病危通知。如果套太深或亏太多，就算利润没凑够，也强行启动 AOE 救灾。

- **启用=同向/跨向修剪：** 手术刀割肉功能。用最新赚钱的单子，一小块一小块切掉亏损的单子。

- **同向/跨向触发层数：** 被套到第几单，手术刀开始出鞘干活。

- **同向/跨向修剪微利\($\)：** 每次切肉，必须留多少纯利。V1\.08\-5 版本有了点差护盾，这里可以压得极低（如 0\.15 刀），只要有一点肉 EA 就疯狂切片重置层数！

### 📡 F组：全息雷达黑盒指标（战车的气象局）

- **ADX动能破壁 / ADX 破壁阈值：** **台风警报器！跑黄金必开！** 阈值（如35\.0）代表风力。风力一旦超过 35（说明爆发了恐怖的单边暴涨暴跌），EA 瞬间断电装死，绝不逆势加仓。

- **启用CCI防飞刀 / CCI 超买防线 / CCI 超卖防线：** 防止在半山腰接飞刀。设成 `180 / -180`，意思是除非行情跌到极度变态、跌出地狱极值，证明跌无可跌了，它才允许去抄底！

- **PA确认 / PA 过滤级别：** 右侧交易的灵魂！就算指标说该抄底了，它还要盯死 K 线：必须看到 K 线收出长长的下影线（Pinbar）或者吞没形态，证明大资金护盘了，才会真正开枪！

- **启用 K线收盘确认：** 防扎针神器！如果一根 K 线暴跌，它死活只加一单，必须等 K 线收盘了才加下一单，废掉极端行情的杀伤力。

### ⏰ L组：时间管理与高级工具（战车的大内总管）

- **全平时连同\(接管单\)一起平：** **关键参数！** 面板上的“一键全平”按钮。开（true）：连同手工单全杀！关（false）：只平 EA 自己的单子，不碰你的手工单。

- **启用 新闻过滤 / 新闻前断电\(分\) / 新闻后断电\(分\)：** 自动拔网线功能！非农、CPI 等大新闻前后（比如各 30 分钟），EA 自动断电休息，绝不趟浑水。

# 🧠 老司机调参配合秘籍（三大实战场景）

参数不是死的，学会几套组合拳，你就能通吃黄金市场：

### 🥊 组合一：200美金“极限保命”铁桶阵

**核心思路：** 资金太小，必须像乌龟一样防守，死等机会，绝不连环加仓。

- **A组\-风险金额：** 设为 `40.0`（最多亏40刀强平保本）。

- **D组\-最大层数：** 设为 `5`（死活不开第6单）。

- **F组\-ADX 破壁阈值：** 调小到 `30.0`（雷达变敏锐，一有单边苗头立刻装死）。

- **F组\-PA确认 / K线收盘确认：** 必须全部开启（`true`），不见兔子不撒鹰。

### 🥊 组合二：几万美分“高频刷单”印钞机

**核心思路：** 资金大抗造，利用震荡行情来回切割赚返佣和微利。

- **B组\-限制周期：** 调成较小的 `PERIOD_M5` 甚至 `PERIOD_M1`（加快开火频率）。

- **E组\-同向触发层数：** 调小到 `3`（早点掏出手术刀开始切片）。

- **E组\-修剪微利\($\)：** 压低到 `0.1` 刀（只要有1毛钱的肉，EA就疯狂对冲割肉，重置网格）。

- **E组\-AOE起爆蓄能\($\)：** 调小到 `3.0` 或 `5.0`（高频触发核弹洗地）。

### 🥊 组合三：非农数据周“防暴走”装甲车

**核心思路：** 明知道这周行情大，提前防飞刀、防深套。

- **L组\-新闻前/后断电\(分\)：** 拉长到 `60` 分钟。

- **H组\-启用布林带开口扩张：** 设为 `true`（布林带喇叭口一旦被撕裂，坚决不逆势接单）。

- **F组\-CCI 超买/超卖防线：** 极端化到 `180 / -180`（不到极值绝不出手）。

- **D组\-逆势拉伸倍数：** 从 1\.5 调到 `2.0`（越跌，网格拉得越极其遥远，不给行情连续套人的机会）。

### 1️⃣ 模块 1：授权与版本信息 \(身份与状态\)

这是 EA 的“身份证”区域，主要用于确认软件的合法性与运行状态。

- **版本确认：** 清晰显示当前运行的是 `极光蓝量化(Aurora EA V1.08-8)`。

- **授权倒计时：** 实时显示网络验证的有效期限（如截图中的“剩余 X天X小时X分钟”），方便用户及时续费，防止授权到期导致策略意外停止。

- **场景应用：** 如果这行字变成了红色的“未授权 \(点击此处重连\) 🔄”，说明网络断开或卡密错误。您不需要去 F7 重新输入，直接用鼠标点一下这行字，系统会在底层强制重新握手联网。

- **收起按钮：** 右上角的 `[收起▲]` 按钮可以折叠整个面板，在复盘或需要看清 K 线时释放图表空间。

### 2️⃣ 模块 2：手动紧急干预面板 \(战术控制台\)

这是为“半自动”交易者和应对突发黑天鹅行情准备的物理按键区，分为控制和一键平仓两大类。

- **停止引擎：** 紧急情况下一键切断 EA 的开仓逻辑。

- **锁仓 Lock：** 瞬间开出与当前净头寸相反的订单，将浮亏死死锁住，防止穿仓。

- **停开首单：** 允许 EA 继续处理现有的网格订单（平仓、拔钉子），但在全部结清后，不再开启新的首单（适合准备下班空仓时使用）。

- **精确平仓：** 提供 `平空单`、`平多单`、`一键全平` 三个红色/蓝色/绿色高亮按钮，方便在极端行情下进行人为的利润落袋或止损斩仓。

### 3️⃣ 模块 3：账户资金动态 \(核心财务报表\)

用最醒目的字号展示交易者最关心的账户资金健康状况。

- **净值 \(Equity\)：** 账户当前的实际价值（截图中为 `$597850.76`）。

- **今日收益：** 每日 0 点重置，实时统计当天赚取的净利润（`+$6.71`）。

- **浮亏峰值：** 记录 EA 运行以来的最大回撤金额（`-$0.28`），这是衡量风控参数是否合理的最直观指标。

### 4️⃣ 模块 4：持仓与打卡监控 \(订单透视镜\)

实时呈现底层仓位的细节分布。

- **浮盈与打卡状态：** 显示当前所有订单的总浮动盈亏，以及“日内打卡下班”功能的开关状态（截图中为 `打卡:关`）。

- **多空阵营明细：** 分别列出多单和空单的层数、总手数、持仓均价以及各自的盈亏情况。这比 MT5 自带的终端窗口看起来更直观。

- **锁仓监控：** 显示当前系统是否处于锁仓状态以及锁仓的手数配比。

### 5️⃣ 模块 5：底层参数透视窗 \(核心配置核对\)

这个区域极其关键，它将您在 F7 设置界面里配置的复杂参数，翻译成人话展示出来，防止实盘中出现“配置错觉”。

- **配置概览：** 显示当前使用的是什么加仓倍数（`分段 1.2倍`）、最大允许层数（`限 15 层`）、最大单笔手数（`0.50 手`）。

- **间距模式：** 明确指出当前网格的拉伸逻辑（如 `浮亏拉伸`），并显示当前多空方向的挂单间距预估。

- **风控防线：** 直观显示硬止损线（`-$5000`）、自动锁仓触发线以及断臂求生线的状态。

- **AOE与修剪：** 展示极光蓝核心的解套武器状态。显示 AOE 资金池的蓄水情况（`$0.00/$10.00`），以及同向/跨向拔钉子触发的层数和利润阈值。

### 6️⃣ 模块 6：战术拨片与状态雷达 \(开关自检\)

通过绿色的“开”和红色的“关”，让您一眼确认各大核心功能是否已经激活。

- **风控拨片：** 止损、锁仓、断臂、智控止盈的状态一目了然。

- **战术拨片：** AOE解套、拔钉子修剪、ST实时激进、ADX动能破壁等高级武器库的开关状态。

- **当前运行状态：** 底部文字总结了当前的策略模式（如 `策略M2`）以及追踪止盈的起步和回撤微点数。

# AOE的优先级排序是：**F7总设置开关 \> 强制唤醒红线 \> 面板拨片开关**。

为了让您形成永久的肌肉记忆，我们可以把它想象成一辆汽车的“自动驾驶与安全气囊系统”：

### 🥇 第一顺位：绝对霸权 —— F7 总开关 \(`启用AOE资金池解套`\)

这是这台机器的“物理电源线”。

- **逻辑：** 如果您在 F7 设置里把它选为 `false`，就相当于直接把 AOE 引擎的电线给剪断了。

- **结果：** 这时候，整个 AOE 模块（包括强制唤醒的探测器）直接从系统内存中死亡。不管您套了 100 层还是浮亏 1 万刀，**强制唤醒也绝对触发不了**，因为报警器根本没通电。面板拨片自然也变成了一个没用的塑料摆设。

### 🥈 第二顺位：紧急豁免权 —— 强制唤醒 \(`唤醒层数/唤醒金额`\)

这是极其危险时的“自动安全气囊”。

- **逻辑：** **前提是 F7 总开关必须是 **`true`**（处于通电状态）。** 在通电的情况下，一旦行情越过了您设定的红线（比如 7 层或 50 刀），安全气囊瞬间引爆。

- **结果：** 它会直接**无视并夺走**您在面板上的控制权。就算您在面板上把拨片点成了“关闭（挂起）”，强制唤醒也会一脚把门踹开，强行启动 AOE 资金池去割肉救火。

### 🥉 第三顺位：战术操作权 —— 面板拨片开关

这是您手里的“方向盘”，级别最低。

- **逻辑：** 只有在 F7 通着电，且**当前浮亏还没有触碰强制唤醒红线**的“安全和平时期”，这个拨片才听您的话。

- **结果：** 行情温和时，您可以随心所欲地点它“开启”去修剪，或者点它“关闭”去保全利润。一旦狼真的来了（触发红线），方向盘就会被系统强行接管。

### 💡 极光蓝实战口诀

弄懂了这个优先级，您以后应对各种极端行情只需要这两招：

4. 👉 **做法：** F7 保持开启，**强制唤醒**设为您能承受的极限（比如 10层/100刀）。然后在**面板拨片**上点击关闭。这样平时它乖乖装死，危急时刻瞬间苏醒护主。
